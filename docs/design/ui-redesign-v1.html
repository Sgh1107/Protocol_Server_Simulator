ProtoSim 界面改版 · 设计稿 v1

目标是把它从"默认 Qt 控件拼起来的样子"变成一台看着可信的工业仪器：信息密度不降反升，但靠层次和留白让人看得下去。 两张图是同一套结构的深浅两版，深色展示报文视图，浅色展示曲线视图——主题只换令牌，不换布局。

  • 值 + 量程条：工程值放大到 17px 等宽数字，下面一条 2px 量程条标出它落在量程的哪个位置，扫一眼就知道"这个温度是不是快撞上限了"。
  • 质量胶囊化：Good / OutOfRange / Bad 从纯文字变成带色点的小胶囊，异常值同时把数字染色，不用逐行读文字。
  • 报文分色：MBAP（灰）/ 单元号（暗）/ 功能码（蓝）/ 数据（白）四段分开，异常帧整行淡红底 + 左侧红条，一眼定位。
  • 命令栏重组：运行/暂停/单步收进分段控件（只有一个主状态），倍速、导出、主题降为次级控件，端点状态变成常驻胶囊。
  • 状态栏拆成指标：原来一句话念完，现在拆成"端点 / 在线 / 收发 / 报文数 / 时钟"五个读数，数字全部等宽对齐。
  • 去掉表格斑马纹：改用 1px 细分割线 + 悬浮高亮，密度更高但不花；选中行用左侧 2px 蓝条 + 淡蓝底，不用整行铺色。
